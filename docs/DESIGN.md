## 0. 무엇을 맞췄나

**직계 상위 `krx-signal-alerts/web`의 토큰을 그대로 잇는다.** 선행 브리핑 메일과 같은 팔레트다
(`--ink #121829` · `--muted #626d8a`). 이 프로젝트는 그 신호를 검증하는 화면이므로 같은 얼굴이어야 한다.

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `--ground` / `--surface` / `--sunk` / `--raise` | `#eff1f5` `#ffffff` `#e5e8ef` `#fafbfd` | `#0d1120` `#151b2c` `#101626` `#1a2135` | 바탕·카드·오목·볼록 |
| `--ink` / `--ink-2` / `--muted` / `--faint` | `#121829` `#3d465f` `#626d8a` `#8b94ac` | `#e4e8f2` `#bac3d8` `#8c97b5` `#6b7694` | 글자 4단계 |
| `--line` / `--line-2` | `#d3d8e4` `#bfc6d6` | `#272f49` `#38425f` | 선·테두리 |
| `--up` / `--down` (+`-w` 연한 것) | `#c9283e` / `#1f63a8` | `#ff6377` / `#5fa6ec` | **등락**만. 판정 색이 아니다 |
| **`--agree` 정합** | **`#0E8A6E`** | `#2A9D85` | 판정 칩 · 분포 차트 |

| 무관 | 테두리 `--line-2` · 글자 `--muted` | 같음 | 배경 없이 |

- 판정 색은 선행 DESIGN **G8**을 잇는다 — *국내 관행상 빨강은 상승이라 정합만 색 계열을 뺐다. 판정은 등락과 다른 축이다.*
  정합 초록만 선행 `#0F6E5C`에서 **`#0E8A6E`로 한 단계 올렸다**: 차트 팔레트 검증기가 채도 바닥(0.087 < 0.1, 회색으로 읽힘)을 지적했다. 칩과 차트가 같은 색을 쓰도록 둘 다 바꿨다.
- 적녹 쌍은 색약 분리가 늘 경계(ΔE 7.4 라이트 · 6.2 다크 — 6~8 대역)라 **색만으로 구별하지 않는다**: 칩은 글자를 달고, 차트는 **직접 라벨 + 불일치에 빗금 무늬**를 보조 표시로 둔다. 네 팔레트(라이트·다크 × 두 색) 전부 검증기 통과 (2026-09-06).
- 글꼴: 상위 웹과 같이 시스템 산세리프(`-apple-system, "Apple SD Gothic Neo", "Malgun Gothic", system-ui`). 숫자·티커는 모노(`ui-monospace, Menlo`). 웹폰트를 새로 들이지 않는다.
- 밀도: 데이터 도구다. 본문 14px · 표 행 40px · 컨트롤 36px · 모서리 6px · 카드 안쪽 16px.

## 1. IA (정보구조)

```
상단 바 (모든 화면)  신호 검증 · [오늘] [이력] [분별력] · 기준일 · 온디맨드 입력 ▸ 검증 요청
────────────────────────────────────────────────────────────────────────
  오늘 (F51)  ──▶  종목 (F52)  ◀──  이력 (F53)
                     ▲
  온디맨드 (F41·F42) ─┘  요청 → 대기 → 처리 중(~1분) → 완료(종목으로) / 실패
  분별력 (F54)   — 독립. 종목으로 가지 않는다 (개별 종목의 앞날을 말하지 않는다)
────────────────────────────────────────────────────────────────────────
하단 띠 (모든 화면)  투자 권고가 아닙니다 · 참고용 테스트        + <meta name="robots" content="noindex">
```

- **최상위는 셋**(오늘·이력·분별력). 종목은 목록에서 들어가는 상세다. 온디맨드는 상단 입력 하나로 어디서든 연다.
- **분별력에서 종목으로 가는 링크를 두지 않는다** — 분포는 군의 관측이고, 거기서 개별 종목을 열면 「이 종목이 맞았나」로 읽는다 (R2).
- URL: `/` 오늘 · `/t/[ticker]?d=YYYY-MM-DD` 종목 · `/history` 이력 · `/discrimination` 분별력 · `POST /api/verify` 온디맨드.

## 2. 와이어프레임 (화면별 구성 요소와 규칙)

### 2-1. 오늘 (F51)
- 머리: 기준일 · 판정 수 칩 (정합 n · 불일치 n · 무관 n) · 상위 자료 신선도(낡았을 때만 한 줄).
- 표: 종목 · 전략 · **판정 칩** · **점수** · 근거 요약(parts 상위 2개) · 생략 갈래 · → 종목.
  기본 정렬 **점수 낮은 것부터**(메일과 같다 — 불일치가 위). 열 머리 클릭 정렬 · 판정/전략 필터 칩.
- 빈 날: 「그날 검증할 신호가 없었다」 + 게이트 상태(`stale` / `gate_timeout`)를 그대로 보인다.

### 2-2. 종목 (F52)
- 머리: 종목명 · 티커 · 시장 · 전략 · **판정 칩 + 점수** · 판정일 · `rules_version` · 출처(batch/ondemand).
- **한계 문구가 접히지 않는 자리에** — 「이 점수는 … 앞으로의 주가를 말하지 않는다」. 점수 바로 아래.
- 점수 구성(parts): 라벨 + 증감. 사각지대(blind_spots) 목록.
- 다섯 갈래를 **세로 순서 고정**: 공시 → 뉴스 → 수급 → 재무 → 공매도. 빈 갈래는 **「생략 — 이유」**로 자리를 남긴다(사라지지 않는다).
  - 공시: 제목(원문) · 날짜 · 규칙 등급 · **DART 원문 링크 필수(N3)** · 본문 요약(오버행·사모 등).
  - 뉴스: 제목(원문 링크) · 날짜 · 매체.
  - 수급: 30일 기관/외국인 순매수 — 부호 있는 가로 막대(등락 토큰) + 누적.
  - 재무: `financial.lines()` 그대로 — 보고서 라벨 포함 · **「이 보고서에 매출액이 없다」**도 한 줄.
  - 공매도: M8 전까지 「생략 — 상위 미수집」.
- 관측(F22·F23): 5·20·60거래일 — 종목 / 지수 / 초과. **미도래는 `—`**. 지수 없으면 초과도 `—` + 「기준선 미도달」.
- 서술(F11): LLM 문장 그대로, 없으면 **「⚠ 서술 생략」**.

### 2-3. 이력 (F53)
- 좌: 날짜 목록(최근 60거래일, 그날 판정 수). 상: 종목 검색.
- 표: 날짜 · 종목 · 판정 · 점수 · **`rules_version`** · 출처 · 5/20/60 초과(도래분만).
- `rules_version`이 바뀐 경계에 **가로 구분선 + 「산식 v1.1부터」** 표시 — 서로 다른 자로 잰 값이 한 표에 섞였음을 보이게.

### 2-4. 분별력 (F54)
- 머리 문장(크게, 접히지 않음): **「이것은 예측이 아니다 — 정합 군과 불일치 군이 갈리는지를 본다」**.
- 구간 셋(5·20·60거래일) 소형 다중: 축은 초과수익(%p), 각 군 **사분위 띠(q1~q3) + 중앙값 눈금 + n 직접 라벨**. 불일치 띠는 빗금.
- **표본 부족(n < 30)이면 띠 대신 「표본 부족 (정합 n=… · 불일치 n=… · 필요 30)」** — 오늘 실제 상태다.
- 겹침(0~1) 한 줄 + `rules_version` · `as_of`. 숫자 표(중앙값·q1·q3·n) 병기(차트 대안).
- **적중률·승률·정확도 숫자는 어디에도 없다** — `discriminate` 반환 타입에 그 칸이 없다.

### 2-5. 온디맨드 (F41·F42)
- 상단 입력(6자리 영숫자) ▸ 「검증 요청」. 상태 패널: 대기 → 처리 중(약 1분, 진행 점) → 완료(→ 종목) / 실패(사유).
- **오늘 남은 요청 n/N** 상시 표시 · 처리 중이면 새 요청 버튼 비활성(동시 1건).
- 「온디맨드 결과는 분별력 집계에 넣지 않는다」 한 줄 (F43).

### 2-6. 공통
- F55 하단 띠 「투자 권고가 아닙니다 · 참고용 테스트」 — 스크롤과 무관하게 항상 보임. `noindex`.
- 다크/라이트: 시스템 설정 따름 + 토글. 토큰만 바꾼다.
- 아이콘은 인라인 SVG 선형 16px 한 벌(외부 링크·정렬·검색). 이모지 없음.

## 3. UI 시안

Claude Design 캔버스 — 아트보드 5장(오늘 · 종목 · 이력 · 분별력 · 온디맨드), 각 1440×900, 라이트/다크 토글(tweak).
정적 목업이다(합의용). 표본 값은 2026-09-03 실제 판정(금강철강 불일치 37 · 대한해운 정합 68 …)에서 가져왔고,
분별력의 5거래일 띠만 **「예시 값」**으로 표시했다(오늘 실제는 전 구간 표본 부족).

- 캔버스: https://claude.ai/code/artifact/e5f05a0c-e2f4-42e1-8450-53f51603cbb7 (2026-09-06 발행 · 비공개)
- 원본: `docs/design/web/*.dc.html` · `canvas.json` — 고칠 때 이 파일을 고쳐 다시 만든다.
  조립 결과물 `docs/design/web/krx-signal-verify-dashboard.html`(에디터 페이로드 약 2 MiB)은 리포에 넣지 않는다(`.gitignore`).

**구현(2026-09-06)**: `web/` — 보호 주소 https://krx-signal-verify-dash.vercel.app (Vercel 로그인 필요). 프로덕션 도메인 `krx-signal-verify.vercel.app`은 자리표시 「비공개」만 보인다(SPEC V10 v0.8).

배치: 윗줄 오늘 → 종목 → 이력, 아랫줄 분별력 → 온디맨드. 각 아트보드 위 메모에 그 화면의 규칙 요지를 적어 두었다.

**검토 요청 항목** (합의가 필요한 결정):
1. 판정 색 — 정합 `#0E8A6E`(선행 `#0F6E5C`보다 한 단계 밝음) · 불일치 `#C9283E`(등락 빨강과 같은 값). 불일치와 상승을 같은 빨강으로 두는 것이 헷갈리면 불일치만 다른 색으로 뗄 수 있다.
2. 오늘 화면 기본 정렬 — 점수 낮은 것부터(메일과 동일). 정합부터 보고 싶으면 반대로.
3. 종목 화면 갈래 순서 — 공시 → 뉴스 → 수급 → 재무 → 공매도 고정, 빈 갈래도 자리를 남김.
4. 분별력 — 사분위 띠 + 중앙값 + n 직접 라벨, 표본 30 미만은 그리지 않음. 히스토그램·점 분포로 바꿀 수 있다.
5. 온디맨드 — 상단 바 입력 하나(별도 페이지 없음), 하루 5건 한도 표시.
