## 8. main.py — 걷는 해골

> verify/main.py — --date · --ticker(온디맨드) · --dry-run · --force · --if-not-verified → 초기 상태 → invoke(). 스텁으로 START→END 완주
> 진행해줘요

테스트 24개. `python -m verify.main --dry-run` → `status=no_signals` exit 0 **완주**.

- 기준일은 **서울 기준 오늘**(UTC면 아침에 하루 밀린다). 「오늘」을 아는 곳은 여기 하나뿐
- 종료 코드: `ok`·`no_signals` → 0 / `stale_data`·`gate_timeout`·`failed` → **1**
- 함정: **argparse는 문자열 기본값도 `type`에 통과시킨다** — `--ticker default=""`가 검증에 걸려 모든 실행이 죽었다

**변이 검사가 약한 테스트 2건을 찾았다**
1. 기준일 UTC 치환이 **안 잡힘** — 한국 낮에는 두 값이 같다 → **UTC 15:30 = KST 익일 00:30 경계 고정**으로 변경
2. `--force`가 no-op을 뚫는지 **안 잡힘** — 양쪽 다 0을 돌려준다 → 게이트 호출을 **관측**하도록 변경

@pytest.mark.parametrize("compound", ALLOWED_OUTCOME_COMPOUNDS)   # 비우면 0개 → 건너뛰기
